# LMRL-Gym Documentation

Welcome to the documentation for **LMRL-Gym**, a benchmark suite and framework for multi-turn reinforcement learning with language models.

This section provides high level information about the project. For installation and running a baseline see [Quickstart](quickstart.md). If you want to add new tasks or algorithms see [Extending](extending.md). For guidance on replicating results visit [Reproducibility](reproducibility.md).
